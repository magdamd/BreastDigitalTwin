# Breast Digital Twin: Towards simulation-guided acceleration of method development

**Phantoms**

The phantoms are defined with the BIfTI format (cite).
There are breast phantoms for 3T and 7T simulation. Both field-strength phantoms ar prepared to be loaded without and with artefacts.
The 3T phantom can include inhomogeneous dB0, inhomogeneous B1+, inhomogeneous B1-.
The 7T phantom can include inhomogeneous B1+ and B1-. 

**Sequences**

 The sequences are written in the Pulseq .seq format (cite). The supplied sequences are based on FLASH and TSE
